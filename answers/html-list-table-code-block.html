How do I create a simple HTML page with a list, a table and a code block?

Short answer

Save the page below as index.html and open it in a browser. It uses <ol> for the list, <table> for the table and <pre><code> for the code block. It needs no libraries or build step. The example content comes from this repository's hw_11_hello_worlds assignment.

The complete page

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Hello World programs</title>
  <style>
    body { font-family: sans-serif; max-width: 40rem; margin: 2rem auto; padding: 0 1rem; }
    table { border-collapse: collapse; }
    th, td { border: 1px solid #999; padding: 0.3rem 0.6rem; text-align: left; }
    pre { background: #f4f4f4; padding: 0.8rem; overflow-x: auto; }
  </style>
</head>
<body>
  <h1>Hello World programs</h1>

  <h2>Steps</h2>
  <ol>
    <li>Install the language runtime.</li>
    <li>Run the program.</li>
    <li>Type your name and press Enter.</li>
  </ol>

  <h2>Run commands</h2>
  <table>
    <thead>
      <tr><th>Language</th><th>File</th><th>Command</th></tr>
    </thead>
    <tbody>
      <tr><td>Python</td><td>hello_world.py</td><td>python3 hello_world.py</td></tr>
      <tr><td>Ruby</td><td>hello_world.rb</td><td>ruby hello_world.rb</td></tr>
      <tr><td>Go</td><td>hello_world.go</td><td>go run hello_world.go</td></tr>
    </tbody>
  </table>

  <h2>Example</h2>
  <pre><code>name = input("What is your name? ")
print(f"Hello, {name}!")</code></pre>
</body>
</html>

How each part works

The list

  • <ol> makes a numbered list; <ul> makes a bulleted one.
  • Each item goes in its own <li> element.
  • You can nest lists by putting another <ul> or <ol> inside an <li>.

The table

ElementPurpose
<table>Wraps the whole table.
<thead> / <tbody>Group the header rows and the data rows.
<tr>One row.
<th>A header cell (bold and centred by default).
<td>A data cell.

Without CSS a table has no borders. The rule border-collapse: collapse plus a border on th, td gives the usual grid.

The code block

  • <pre> keeps spaces, indentation and line breaks exactly as written.
  • <code> marks the text as code; browsers show it in a monospace font.
  • Escape the characters that HTML treats specially: write &lt; for <, &gt; for > and &amp; for &. Otherwise the browser reads code such as <div> as markup.
  • Start the code right after <pre><code>. A line break there shows up as an empty first line.

Escaping code automatically with Python

If you generate the page from a script, let the standard library do the escaping:

import html
from pathlib import Path

source = Path("hw_11_hello_worlds/hello_world.py").read_text().rstrip()
block = f"<pre><code>{html.escape(source)}</code></pre>"
print(block)

Checking the page

  • Open the file directly in a browser (File → Open, or drag it into a window).
  • Paste it into the W3C validator to catch unclosed tags.
